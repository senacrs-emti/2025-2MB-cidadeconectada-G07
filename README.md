# 2025-2MB-cidadeconectada-G07

🌞 Solar Beam

Um portal moderno dedicado a fornecer informações claras, práticas e visuais sobre energia solar, sustentabilidade e tecnologias renováveis.

🚀 Sobre o projeto

Solar Beam é um site criado para ajudar pessoas a entenderem como a energia solar funciona, seus benefícios, custos, aplicações e o impacto positivo no meio ambiente. Nosso objetivo é tornar o conhecimento acessível e incentivar a adoção de energias limpas.

✨ Funcionalidades

Informações atualizadas sobre energia solar

Artigos educativos e explicativos

Interface simples, intuitiva e responsiva

Recursos visuais que facilitam o aprendizado no estilo 2000

🛠️ Tecnologias utilizadas

HTML

CSS

JavaScript

photoshop

📌 Objetivo

Promover o entendimento e a adoção de soluções sustentáveis, mostrando como cada pessoa pode contribuir para um futuro mais limpo com pequenas mudanças.
